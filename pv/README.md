# 《花骨朵》PV（全曲重制版）

以完整原曲作为背景音乐、画面全部重做的动态 PV。成片为 `../花骨朵_PV.mp4`（1920×1080，30 fps，170 秒，带运动模糊）。

画面分两部分：

- **插画**：34 个编号的「画面槽位」，用 GPT 等图像模型按 [`PROMPTS.md`](PROMPTS.md) 里的提示词生成，放进 `assets/images/` 即可。还没有图的槽位显示占位画面（标着 `S05 少女与孩子` 这样的编号），方便对照提示词。
- **动态设计**：镜头、歌词排版、粒子、图形、转场、调色和后期全部由代码按时间生成，和音乐逐拍对齐。

## 制作思路

- **逐字动态歌词**：Demucs 分离人声，wav2vec2 强制对齐每一个字（302 个音节），再吸附到 120 BPM 的十六分音符网格。40 句歌词各有单独的版式与入场 / 出场动画（砸入、下落、翻转、遮罩升起、拉伸、故障、打字机、冰冻抖动、墨迹洇开、斜切、碎裂……），重点句带空心描边大字和回声描边。每句下方是逐字点亮的拼音和英文译文。
- **2.5D 镜头**：图片、图形、歌词、粒子各在不同的景深上，镜头推拉、平移、旋转时近处的层移动得更多，形成视差；手持漂移、底鼓推镜、军鼓左右摆动和冲击震动叠加在每个镜头的运动上。
- **运动模糊**：每一帧由 6 个子帧在 180° 快门内平均而成，快速的文字、粒子和镜头运动都有真实的拖影。
- **鼓点驱动**：Demucs 分离出鼓轨，检测底鼓 / 军鼓 / 镲。底鼓推镜与震动，军鼓闪白、色散、故障切片，副歌里镜头随军鼓左右摆。
- **转场**：甩镜（带拖影）、推拉穿越、圆形扩散、斜切光刃、百叶、墨迹晕染、叠化、故障撕裂、闪白、冲击下坠。
- **图形与特效**：毛笔扫痕、泼墨、红墨晕染、窗棂线框、自绘小屋、二十四节气转盘、日夜交替、群蝶、花瓣爆发、雪与散景、火星、体积光、变形宽银幕光晕、光漏、颗粒、取景框 HUD（小节 / 拍子计数）、宽银幕遮幅。

## 补画面

1. 按 [`PROMPTS.md`](PROMPTS.md) 生成图片（先生成 S00 角色设定图，作为之后每张女主角图片的参考）。
2. 存为 `assets/images/05.png` 这样的名字（`S05.png`、`05_少女与孩子.jpg` 也可以；png / jpg / webp 均可）。
3. 重新渲染。放了几张就替换几张，其余仍是占位画面。
4. 可选：`python tools/ai/make_layers.py` 用景深模型把图片拆成前景 / 背景两层，镜头运动时有真实视差。

提示词写在 `assets/slots.json`（统一画风、女主角设定、每个槽位的中英文描述、主体位置和色调）；改完运行 `node tools/make_prompts.mjs` 重新生成 `PROMPTS.md`，其中的出现时间直接取自分镜。

## 渲染

成片只依赖已提交的素材（`assets/`：歌词对齐、鼓点数据、槽位提示词、字体，以及你放进去的图片）：

```bash
node pv/tools/render.mjs                       # 输出 花骨朵_PV.mp4（约 20 分钟，4 核）
node pv/tools/render.mjs --stills 16.6,47.5    # 渲染指定时间点的静帧到 pv/build/stills
node pv/tools/render.mjs --from 79 --to 95 --samples 2 --out chorus.mp4   # 快速预览某一段
```

常用参数：`--fps 30`、`--samples 6`（运动模糊子帧数，1 为关闭）、`--shutter 180`（快门角度）、`--bitrate 4M`（两遍编码，控制文件大小）或 `--crf 21`、`--workers 4`。

需要 Node 18+、Playwright 的 Chromium 和 ffmpeg。实时预览：用静态服务器托管 `pv/`（例如 `npx http-server pv`），打开 `index.html` 拖动或播放（预览不带运动模糊）。

### 重新分析音频（可选）

需要 Python 环境：`torch`、`torchaudio`、`transformers`、`librosa`、`demucs`、`pypinyin`。全部在 CPU 上运行。

```bash
ffmpeg -i 花骨朵.mp4 -vn song.wav
python -m demucs -n htdemucs -o sep song.wav                       # 分离人声 / 鼓 / 贝斯 / 其他
python pv/tools/ai/align_lyrics.py sep/htdemucs/song/vocals.wav    # → pv/assets/lyrics.json
python pv/tools/annotate_lyrics.py                                 # 加拼音和英文译文
python pv/tools/ai/analyze_song.py sep/htdemucs/song               # → pv/assets/timing.json
python pv/tools/fetch_fonts.py                                     # 按用到的字重新下载字体子集
```

## 代码结构

| 文件 | 作用 |
|---|---|
| `src/story.js` | 全曲分镜：镜头与槽位、镜头运动、调色、40 句歌词的排版与动画、特效段落 |
| `src/main.js` | 合成器：运动模糊子帧 → 镜头 / 转场 → 歌词 → 后期（色散、辉光、体积光、光晕、字幕、HUD、遮幅） |
| `src/camera.js` | 2.5D 镜头：景深分层、全局手持与鼓点运动、镜头运动预设 |
| `src/slots.js` | 画面槽位：读取图片或生成占位画面，按镜头绘制 |
| `src/transitions.js` | 双镜头转场（甩镜、穿越、圆形、斜切、百叶、墨迹、叠化、故障） |
| `src/lyrics.js` | 逐字动态排版引擎（布局、入场与出场动画、描边大字、拼音英文字幕） |
| `src/graphics.js` | 动效图形库（HUD、冲击波、窗棂、小屋、节气转盘、日月、毛笔、泼墨、蝴蝶、故障） |
| `src/particles.js` | 花瓣、雪、火星、尘埃（每个粒子都是关于时间的解析函数，带景深） |
| `src/plum.js` | 程序化水墨梅枝（标题与片尾） |
| `src/fx.js` | 色散、辉光、体积光、光晕、颗粒、暗角、墨迹遮罩等后期效果 |
| `tools/render.mjs` | 无头 Chromium 逐帧渲染并编码 |
| `tools/make_prompts.mjs` | 生成 `PROMPTS.md` |
| `tools/ai/*` | 歌词对齐、鼓点分析、景深分层 |

所有元素都是时间的确定性函数，帧可以任意顺序、并行渲染。
