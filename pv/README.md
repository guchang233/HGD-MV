# 《花骨朵》PV

根据原版 MV（`../花骨朵.mp4`）制作的 74 秒宣传 PV，成片为 `../花骨朵_PV.mp4`（1920×1080，60 fps，H.264 + AAC）。

PV 延续原版 MV 的视觉语言：宣纸白、墨线、朱红与绛红、竖排宋体字，以及首尾呼应的梅枝。水墨梅花、花开、花瓣、雪、光效、字体动画、转场和胶片质感全部由代码程序化生成，再与原版 MV 的画面合成。

## 结构

音轨从原 MV 中剪出。歌曲是稳定的 120 BPM（强拍在 0.055 + 2n 秒），每个剪辑点都落在小节内的同一位置，所以拼接后节拍始终连续。

| PV 时间 | 原 MV 素材 | 段落 | 内容 |
|---|---|---|---|
| 0.0 – 6.1 | 前奏 0 – 6 秒 | 墨梅开场 | 一道光缝展开成宣纸，水墨梅枝从画角生长，花苞随前奏的音符成簇绽放；题字「含苞待放」与「天依」印章落款，镜头随后推入主花。 |
| 6.1 – 12.1 | 前奏 4 – 13.5 秒 | 回忆 | 从梅花匹配剪辑到她手中的花；墨迹晕染转入对镜双脸，再到红线翻花绳。 |
| 12.1 – 16.0 | 前奏 12 – 16 秒 | 标题 | 「花骨朵」三字随节拍逐字洇开在纸上，红线划出下划线，随前奏的上扬音效冲入标题。 |
| 16.0 – 33.4 | 61.99 – 79.4 秒 | 我想要死在春天里 | 红色房间、新娘（「野蛮生长在春泥」逐词冲击）、花轿，配合火星、落花和暖色漏光。 |
| 33.4 – 56.1 | 127.45 – 150 秒 | 最终副歌 | 白闪切入雪夜；原 MV 的每个剪辑点和歌词出现都配有推镜、震动或色散。唱到「花骨朵」时红光爆开，数百片花瓣冲向镜头；随后是「错过的不肯罢休」，以及带体积光的日出。 |
| 56.1 – 67.4 | 150 – 161.4 秒 | 尾声 | 「眼看着那缕胭脂红」，最后梅枝的花瓣被风吹散。 |
| 67.4 – 74.5 | — | 片尾 | 呼应原 MV 标题卡：白梅落在晕开的红墨上，配标题、制作人员名单和「完整版MV 现已上线」。 |

每段镜头的切换都精确对齐原 MV 自己的剪辑帧（从素材逐帧测得），镜头运动不会在同一镜头中途跳变。歌词沿用原 MV 的字幕设计；最终副歌里镜头保持 1:1，贴边排布的歌词不会被裁掉。

## 渲染

环境需要 Python 3（`numpy`、`scipy`）、`ffmpeg`、Node 18+ 和 Playwright 的 Chromium。

```bash
python3 pv/tools/build_audio.py      # 剪音轨，并生成节拍/起音分析（pv/assets/timing.json）
python3 pv/tools/extract_frames.py   # 提取 MV 镜头到 pv/build/frames（裁黑边、降噪、放大 1.6 倍）
node pv/tools/render.mjs             # 无头浏览器逐帧渲染，并编码为 花骨朵_PV.mp4
```

`render.mjs` 常用参数：

- `--stills 3,16.5,47.2`：渲染指定时间点的静帧到 `pv/build/stills`，用于检查画面。
- `--from 30 --to 40 --fps 30 --out draft.mp4`：快速渲染某一段的草稿。
- `--workers N` 控制并行数，`--crf N` 控制画质。已渲染的帧会自动跳过，加 `--force` 可重新渲染。

实时预览：用静态服务器托管 `pv/` 目录（例如 `npx http-server pv`），打开 `index.html`，拖动进度条，或点「播放」跟随音轨播放。

## 代码结构

| 文件 | 作用 |
|---|---|
| `src/timeline.js` | 分镜表、镜头运动和卡点事件，大部分调整都改这里 |
| `src/plum.js` | 程序化水墨梅枝、花苞和梅花 |
| `src/particles.js` | 花瓣、雪、火星、尘埃粒子，每个粒子都是关于时间的解析函数 |
| `src/fx.js` | 墨迹晕染遮罩、色散、辉光、体积光、漏光、颗粒和暗角 |
| `src/type.js` | 思源宋体（Noto Serif SC）字体、墨迹洇开动画和印章 |
| `src/footage.js` | 逐帧精确的 MV 素材读取和虚拟摄像机 |
| `src/main.js` | 合成器：镜头 → 胶片后期 → 遮幅 |

渲染是确定性的：所有元素都是时间的纯函数，随机数使用固定种子，所以帧可以任意顺序、并行渲染，结果完全一致。
